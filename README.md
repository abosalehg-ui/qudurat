## 📋 نظرة عامة

**قدراتي** هي منصة تعليمية تفاعلية مصممة خصيصاً لطلاب المرحلة الثانوية في المملكة العربية السعودية للتدريب على اختبار القدرات العامة (قياس). تجمع المنصة كل ما يحتاجه الطالب في مكان واحد مع تحليل ذكي للأداء، صاحب الفكرة: سلطان بن عامر الرحيلي.

### ✨ لماذا قدراتي؟

- 🎯 **تركيز على الاختبار الحقيقي** - أسئلة تحاكي نمط اختبار قياس
- 📊 **تحليل ذكي** - تتبع نقاط القوة والضعف تلقائياً
- 📱 **متجاوب بالكامل** - يعمل على جميع الأجهزة
- 🌙 **واجهة عربية** - تصميم يدعم RTL بالكامل
- 💾 **حفظ تلقائي** - لا تفقد تقدمك أبداً

## 🛠️ التثبيت والاستخدام

### الطريقة 1: الاستخدام المباشر
قم بزيارة [الموقع المباشر](https://abosalehg-ui.github.io/qudurat/) واستخدمه فوراً!

### الطريقة 2: التثبيت المحلي

```bash
# استنساخ المستودع
git clone https://github.com/abosalehg-ui/qudurat.git

# الانتقال للمجلد
cd qudurat

# فتح الملف في المتصفح
# يمكنك فتح index.html مباشرة أو استخدام خادم محلي

# باستخدام Python
python -m http.server 8000

# أو باستخدام Node.js
npx serve .
```

ثم افتح المتصفح على: `http://localhost:8000`

### الطريقة 3: استضافة على GitHub Pages

1. Fork هذا المستودع
2. اذهب إلى Settings > Pages
3. اختر Branch: `main` و Folder: `/ (root)`
4. انتظر دقائق وسيكون موقعك جاهزاً!

## 📁 هيكل المشروع

```
qudurat/
│
├── 📄 index.html          # هيكل الصفحات (HTML فقط)
├── 📄 styles.css          # كل الأنماط بما فيها الوضع الليلي والطباعة
├── 📄 app.js              # منطق التطبيق (تنقّل، اختبارات، لوحة تحكم، تلعيب)
├── 📄 app-core.js         # الدوال النقية المشتركة (قابلة للاختبار في Node)
├── 📄 questions.js        # قاعدة أسئلة واختبارات العينة
├── 📄 service-worker.js   # التخزين المؤقت للعمل دون اتصال (PWA)
├── 📄 manifest.json       # تعريف تطبيق الويب + الأيقونات
├── 📁 scripts/            # check-questions.mjs: فحص سلامة قاعدة الأسئلة
├── 📁 tests/              # اختبارات وحدات (node --test، بلا اعتماديات)
├── 📁 .github/workflows/  # CI: فحص الأسئلة + الاختبارات على كل تعديل
├── 📄 README.md           # ملف التوثيق
└── 📄 LICENSE             # رخصة MIT
```

> **ملاحظة:** لا يحتاج المشروع إلى أي نظام بناء أو اعتماديات — الملفات تُقدَّم كما هي من أي استضافة ثابتة. لتشغيل الفحوصات محلياً: `node scripts/check-questions.mjs` و`node --test tests/*.test.cjs`.

## 💾 تخزين البيانات

يستخدم الموقع `localStorage` لحفظ البيانات محلياً:

| المفتاح | المحتوى |
|---------|---------|
| `qudurat_data` | محتوى المستخدم فقط (أسئلته المخصصة وتعديلاته) + تقدمه — أسئلة العينة تُقرأ من `questions.js` عند كل تشغيل حتى تصل تحديثات المحتوى للجميع |

```javascript
// مثال على هيكل البيانات
{
  questions: [...],      // قاعدة بيانات الأسئلة
  tests: [...],          // الاختبارات المتاحة
  progress: {            // تقدم المستخدم
    streak: 5,
    questionsAnswered: 150,
    correctAnswers: 120,
    savedQuestions: [1, 5, 12],
    testResults: [...]
  }
}
```

## 🎨 التخصيص

### تغيير الألوان الرئيسية

في بداية ملف `styles.css`، ابحث عن `:root` وعدّل المتغيرات:

```css
:root {
    --primary: #1a5f7a;        /* اللون الرئيسي */
    --secondary: #f39c12;       /* اللون الثانوي */
    --success: #27ae60;         /* لون النجاح */
    --danger: #e74c3c;          /* لون الخطأ */
    /* ... */
}
```

### إضافة أسئلة جديدة

يمكنك إضافة أسئلة عبر:
1. **لوحة التحكم** في الموقع (الطريقة الأسهل)
2. **تعديل الكود** مباشرة في دالة `getSampleQuestions()` داخل ملف `questions.js`

```javascript
{
    id: 100,
    section: 'verbal',           // 'verbal' أو 'quant'
    subcategory: 'analogy',      // الفئة الفرعية
    difficulty: 'medium',        // 'easy', 'medium', 'hard'
    text: 'نص السؤال هنا',
    options: ['خيار أ', 'خيار ب', 'خيار ج', 'خيار د'],
    correct: 0,                  // رقم الإجابة الصحيحة (0-3)
    explanation: 'شرح الإجابة'
}
```
